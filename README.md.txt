## Project Description
A web-based system that uses Linear Programming to help users choose the optimal combination of burgers within a budget to maximize taste satisfaction.

## LP Formulation
**Objective:** Maximize Z = 9x₁ + 8x₂ + 7x₃ + 5x₄

**Constraints:**
- Budget: 6x₁ + 5x₂ + 4.5x₃ + 4x₄ ≤ 15
- Max 2 burgers: x₁ + x₂ + x₃ + x₄ ≤ 2

## How to Run
1. Install XAMPP
2. Copy folder to `htdocs`
3. Import `database.sql` to phpMyAdmin
4. Start Apache & MySQL
5. Visit `http://localhost/optiburger`
